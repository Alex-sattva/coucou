Architecture — one chosen approach

The notch window, panel, shape, mode machinery and the Mochi renderer already exist. Keep all of them; replace only the island's default content.

  • New surface: HarnessVoiceView replaces OverviewView as the .home body dispatched from IslandViewContent.swift:5.
  • Reused verbatim: IslandWindowController (islandSize :1143, setMode/expand/collapse), IslandShape (:179), IslandHeader (:465), BotCanvasView (:5), MiniBotCanvasView (:187), TickerView (:3434), ApprovalView (:296), BotState/BotEngine (:171), AgentTask (IslandTypes.swift:49), PillCatalog (:48).
  • New presentation state: VoiceHarnessModel: ObservableObject (@MainActor) owns presentation only — focused workspace, composer text, suggestion, summary visibility, roster order. It reads AgentTask/HookServer; it does not duplicate them.
  • Routing: WorkspaceRouter behind a WorkspaceRouting protocol (jev is not in Swift today — ship a deterministic KeywordRouter first, add a JevRouter later). Pure logic, tested.

Out of scope / Do NOT

  • Do NOT touch windows/ (Tauri) — macOS only this round.
  • Do NOT change window geometry: islandSize, IslandShape, the panel, or IslandStateMachine transitions.
  • Do NOT rename or edit pill IDs in PillCatalog.swift — a stable contract.
  • Do NOT restyle Settings, Upload, Greeting, chat or integration cards.
  • Do NOT add a third-party dependency (no STT SDK, no Rive/Lottie).
  • Do NOT store secrets outside the Keychain.
  • Do NOT implement real speech-to-text or wake word: the mic is a push-to-talk toggle feeding the existing text path. Leave TODO(STT); do not fake a transcript.
  • Do NOT persist threads/checkpoints to disk yet.
  • Do NOT hand-edit .xcodeproj — XcodeGen only.

Gaps to flag to the manager

These do not exist in Swift today; this plan builds them fresh. Call them out rather than assuming:

  • jev routing — prototype-only (harness-main-voice.html:317); shipped routing is pill-id based (HookServer.swift:336).
  • Per-folder OpenCode run — runs in the home dir, parses at exit (no live streaming, no --cwd).
  • Thread store / rewind — no thread or checkpoint type exists.
  • Stop / interrupt UI — only the 120 s watchdog exists.
  • Cost/context meter · MCP config · wake word · background multi-run — prototype-only.
