Privacy Policy

Last updated: October 8, 2026
In short: Coucou has no account, no analytics, no ads and no tracking. The developer receives none of your data. Everything stays on your computer (Mac or PC), except what you choose to send to the services you connect yourself.

1. Who is responsible

Coucou is published by Louis Raillé, an individual developer based in France (“we”). Contact: raillelouis@gmail.com.

2. Data we collect

None. Coucou does not send any data to us or to any server we operate. There is no telemetry, no crash reporting service, no advertising identifier and no third-party SDK.

4. Services you connect yourself

Coucou only talks to the services you configure, directly from your Mac, using your own keys. Those services process your data under their own privacy policies:

  • Anthropic (Claude API) — when you chat using Anthropic or ask about a file or a window, the text you type, the file content and/or the window context you chose are sent to Anthropic. When you open the chat or Settings, the list of available models is also fetched from the Anthropic API using your key. (macOS) If you choose Claude in Settings → General → Understanding, each time you type in Mochi's bar or speak to it, these are sent to Anthropic so Claude can decide what to do: your words; for each running agent session its id, agent name, folder, state, title and last prompt (up to 200 characters); up to 40 of your project folders (name, path and the agent you used last there). No transcripts, agent replies or file contents are sent. Anthropic privacy policy.
  • Google AI (Gemini API) (macOS) — when you chat using Google AI, the text you type and the current conversation are sent to Google's Gemini API. If you attached a window, the app name, title and URL are also sent. If you attached a file, only its name is sent (file content is only sent to Anthropic or to a local model server you connected). The list of available models is fetched when you open the chat. Google privacy policy.
  • OpenAI (macOS) — when you chat using OpenAI, the text you type and the current conversation are sent to the OpenAI API. If you attached a window, the app name, title and URL are also sent. If you attached a file, only its name is sent (file content is only sent to Anthropic or to a local model server you connected). The list of available models is fetched when you open the chat. OpenAI privacy policy.
  • Ollama / LM Studio (macOS) — when you chat using a local model, the text you type, the current conversation, and the content of any attached text file (up to 24 000 characters) are sent to the server address you configured in Settings → Chat → Local models. By default that address is 127.0.0.1 on your Mac — nothing leaves your computer. If you point it at a remote server, that server receives the data. The server address is stored in your Mac's user preferences (not the Keychain). The list of available models is fetched each time you open the model picker.
  • Mochi assistant (macOS, GitHub build) — Mochi has its own small assistant, off by default: nothing is sent until you switch it on and pick a provider and model in Settings → General → Mochi assistant. Once on, each time you type in Mochi's bar or speak to it, these are sent to the provider you picked there (Anthropic, OpenAI, Google AI, OpenCode Zen, a server you run: Ollama or LM Studio, which keeps everything on your Mac when it is local; or your own Claude Code login, see below): your words, the name, folder and usual agent of up to 40 of your projects, what your running agents are doing (project, state, last request up to 200 characters, the one-line report they wrote), and the earlier turns of that conversation (the last 40 messages, also kept in ~/Library/Application Support/NotchBuddy/mochi-brain.json until you press “Clear Mochi's conversation”). No file contents, agent replies or transcripts are sent. The assistant can open apps, web links and files on your Mac when you ask, and runs no command; it reads none of your files: work is done by your coding agents, and every permission they ask for still waits for your click. The pile-up digest (“3 agents need you”) is built on your Mac with no model call. Claude (your Claude Code login): if you pick this provider, Mochi runs the Claude Code you already have installed, as one background process in a private folder of its own (~/Library/Application Support/NotchBuddy/mochi-home), with none of your hooks, plugins, CLAUDE.md files, settings or other tools. The same things listed above go to Anthropic through your own Claude login, and they count against your Claude Code usage. Coucou never reads your Claude credentials, and the conversation is kept by Claude Code itself (a session on your Mac), not in mochi-brain.json; “Clear Mochi's conversation” starts a new one.
  • Stripe, GitHub, Vercel, Resend, Notion, Cal.com, n8n — Coucou reads data from your own accounts (payments, repositories, deployments, emails, pages, bookings, workflow runs) to display them. For GitHub specifically, Coucou also reads your open pull requests, reviews requested on you, CI status of your repositories' default branches, and your contribution calendar (the green squares on your profile); this data is kept in memory only and deleted when the app quits. Coucou only reads from them.

We have no access to these requests or their responses.

5. Claude Code, Gemini CLI, Antigravity and Codex hooks

If you install the Claude Code hooks, Claude Code sends session events to Coucou through a local connection on your computer. If you install the Gemini CLI, Antigravity or Codex hooks, those agents send their session events the same way. These events never leave your computer through Coucou. If you install the Plan usage status line, Claude Code also passes the percentage used and the reset times of your plan windows to Coucou through the same local connection; nothing leaves your computer. Before changing any settings file (~/.claude/settings.json, ~/.gemini/settings.json, ~/.gemini/config/hooks.json, ~/.codex/hooks.json), Coucou makes a dated backup and shows you the changes. File edits (the old and new text received from Edit, MultiEdit and Write hooks) are kept in memory for the duration of the session and deleted when the session ends or after one hour of inactivity; they never leave your computer. Agents that Mochi starts itself (macOS, GitHub build): when you confirm “Start Claude Code / OpenCode in …”, Coucou runs that agent for you in the background, with no terminal window, in the project folder. It uses the agent's own login and settings and talks to the agent's own provider: Coucou sends nothing there itself. OpenCode is started with a per-process configuration (never written to your OpenCode files) that adds a local “report” tool the agent uses to tell Mochi its one-line result. Permission requests those agents make appear in the notch and are only answered by your click; OpenCode follows your own OpenCode permission settings (with its defaults it edits files and runs commands without asking). Mochi starts agents itself only while the assistant is on; otherwise “Start” opens your terminal as before. When you press “Open session”, the background agent is stopped and the same conversation opens in your terminal.

6. Apple Music

If you activate the Apple Music pill (macOS, GitHub build), Coucou reads the current track (title, artist, album) from Music on your Mac to display it in the notch, and only sends play, pause or skip commands to Music when you click. Nothing leaves your computer.

7. Email

When you send a file by email, the message is created and sent by your own Mail app. Coucou never sends email by itself.

8. System permissions

Depending on the version and the features you use, macOS may ask you to allow Automation (Mail, Terminal, Music), Accessibility (to read the title of the window you attach) or Screen Recording (to capture a window you attach). These are only used for the feature you triggered and can be revoked at any time in System Settings → Privacy & Security. The Windows and Linux versions ask for no special permission. On Linux, installing the .deb or .rpm package needs administrator rights; the AppImage doesn't.

9. Children

Coucou is a developer tool and is not directed at children.

10. Your rights

Since we hold no personal data about you, there is nothing for us to access, correct or delete. For data held by a service you connected, please contact that service. If you live in the EU, you can also contact your data protection authority (in France: the CNIL).

11. Changes

4. Services que tu connectes toi-même

Coucou ne communique qu’avec les services que tu configures, directement depuis ton Mac, avec tes propres clés. Ces services traitent tes données selon leur propre politique :

  • Anthropic (API Claude) : quand tu discutes via Anthropic ou poses une question sur un fichier ou une fenêtre, le texte saisi, le contenu du fichier et/ou le contexte de la fenêtre choisie sont envoyés à Anthropic. À l’ouverture du chat ou des Réglages, la liste des modèles disponibles est aussi récupérée depuis l’API d’Anthropic avec ta clé. Politique de confidentialité d’Anthropic.
  • Google AI (API Gemini) (macOS) : quand tu discutes via Google AI, le texte saisi et la conversation en cours sont envoyés à l’API Gemini de Google. Si une fenêtre est attachée, le nom de l’app, le titre et l’URL sont aussi envoyés. Si un fichier est attaché, seul son nom est envoyé (le contenu d’un fichier ne part que chez Anthropic ou vers le serveur de modèle local que tu as connecté). La liste des modèles disponibles est récupérée à l’ouverture du chat. Politique de confidentialité de Google.
  • OpenAI (macOS) : quand tu discutes via OpenAI, le texte saisi et la conversation en cours sont envoyés à l’API OpenAI. Si une fenêtre est attachée, le nom de l’app, le titre et l’URL sont aussi envoyés. Si un fichier est attaché, seul son nom est envoyé (le contenu d’un fichier ne part que chez Anthropic ou vers le serveur de modèle local que tu as connecté). La liste des modèles disponibles est récupérée à l’ouverture du chat. Politique de confidentialité d’OpenAI.
  • Ollama / LM Studio (macOS) : quand tu discutes via un modèle local, le texte saisi, la conversation en cours et le contenu de tout fichier texte attaché (jusqu’à 24 000 caractères) sont envoyés à l’adresse de serveur configurée dans Réglages → Chat → Local models. Par défaut, cette adresse est 127.0.0.1 sur ton Mac — rien ne quitte ton ordinateur. Si tu la pointes vers un serveur distant, ce serveur reçoit les données. L’adresse est conservée dans les préférences utilisateur de ton Mac (pas dans le trousseau). La liste des modèles disponibles est récupérée à chaque ouverture du sélecteur de modèle.
  • Assistant de Mochi (macOS, version GitHub) : Mochi a son propre petit assistant, désactivé par défaut : rien n’est envoyé tant que tu ne l’actives pas et que tu ne choisis pas un fournisseur et un modèle dans Réglages → Général → Mochi assistant. Une fois activé, à chaque fois que tu écris dans la barre de Mochi ou que tu lui parles, ceci est envoyé au fournisseur que tu as choisi là (Anthropic, OpenAI, Google AI, OpenCode Zen, un serveur à toi : Ollama ou LM Studio, ce qui garde tout sur ton Mac s’il est local ; ou ta propre connexion Claude Code, voir plus bas) : tes mots, le nom, le dossier et l’agent habituel de 40 de tes projets au plus, ce que font tes agents en cours (projet, état, dernière demande jusqu’à 200 caractères, la phrase de bilan qu’ils ont écrite) et les échanges précédents de cette conversation (les 40 derniers messages, aussi gardés dans ~/Library/Application Support/NotchBuddy/mochi-brain.json jusqu’à ce que tu appuies sur « Clear Mochi’s conversation »). Aucun contenu de fichier, aucune réponse d’agent ni transcription n’est envoyé. L’assistant peut ouvrir des apps, des liens web et des fichiers sur ton Mac quand tu le demandes, et ne lance aucune commande ; il ne lit aucun de tes fichiers : le travail est fait par tes agents de code, et chaque permission qu’ils demandent attend toujours ton clic. Le résumé « 3 agents ont besoin de toi » est construit sur ton Mac, sans appel à un modèle. Claude (ta connexion Claude Code) : si tu choisis ce fournisseur, Mochi lance le Claude Code que tu as déjà installé, en un seul processus d’arrière-plan dans un dossier privé à lui (~/Library/Application Support/NotchBuddy/mochi-home), sans aucun de tes hooks, plugins, fichiers CLAUDE.md, réglages ni autres outils. Les mêmes éléments que ci-dessus partent chez Anthropic via ta propre connexion Claude, et comptent dans ton usage de Claude Code. Coucou ne lit jamais tes identifiants Claude, et la conversation est gardée par Claude Code lui-même (une session sur ton Mac), pas dans mochi-brain.json ; « Clear Mochi’s conversation » en démarre une nouvelle.
  • Stripe, GitHub, Vercel, Resend, Notion, Cal.com, n8n : Coucou lit les données de tes propres comptes (paiements, dépôts, déploiements, e-mails, pages, rendez-vous, exécutions de workflows) pour les afficher. Pour GitHub spécifiquement, Coucou lit aussi tes pull requests ouvertes, les revues de code qui t'attendent, l'état CI de la branche par défaut de tes dépôts et ton calendrier de contributions (les carrés verts de ton profil) ; ces données sont conservées uniquement en mémoire et supprimées à la fermeture de l'app. Coucou ne fait que lire.

Le développeur n’a accès ni à ces requêtes ni à leurs réponses.

5. Claude Code, Gemini CLI, Antigravity et Codex

Si tu installes les hooks Claude Code, Claude Code envoie les événements de session à Coucou par une connexion locale sur ton ordinateur. Si tu installes les hooks Gemini CLI, Antigravity ou Codex, ces agents envoient leurs événements de la même façon. Coucou ne les fait jamais sortir de ton ordinateur. Si tu installes le relais de jauge de forfait (Plan usage), Claude Code transmet aussi à Coucou, par la même connexion locale, les pourcentages utilisés et les heures de remise à zéro de tes fenêtres de forfait ; rien ne quitte ton ordinateur. Avant de modifier un fichier de configuration (~/.claude/settings.json, ~/.gemini/settings.json, ~/.gemini/config/hooks.json, ~/.codex/hooks.json), Coucou en fait une sauvegarde datée et te montre les changements. Les modifications de fichiers (l'ancien et le nouveau texte reçus via les hooks Edit, MultiEdit et Write) sont conservées en mémoire pendant la durée de la session et supprimées à la fin de la session ou après une heure d'inactivité ; elles ne quittent jamais ton ordinateur. Agents que Mochi démarre lui-même (macOS, version GitHub) : quand tu confirmes « Start Claude Code / OpenCode in … », Coucou lance cet agent pour toi en arrière-plan, sans fenêtre de terminal, dans le dossier du projet. Il utilise la connexion et les réglages propres à l’agent et parle à son propre fournisseur : Coucou n’y envoie rien lui-même. OpenCode est démarré avec une configuration propre au processus (jamais écrite dans tes fichiers OpenCode) qui ajoute un outil local « report » grâce auquel l’agent dit à Mochi son résultat en une phrase. Les demandes de permission de ces agents s’affichent dans le notch et ne reçoivent de réponse que par ton clic ; OpenCode suit tes propres réglages de permissions OpenCode (par défaut, il modifie des fichiers et lance des commandes sans demander). Mochi ne démarre un agent lui-même que lorsque l’assistant est activé ; sinon « Start » ouvre ton terminal comme avant. Quand tu appuies sur « Open session », l’agent d’arrière-plan est arrêté et la même conversation s’ouvre dans ton terminal.

6. Apple Music

Si tu actives la pastille Apple Music (macOS, version GitHub), Coucou lit le morceau en cours (titre, artiste, album) depuis l’app Musique de ton Mac pour l’afficher dans le notch, et n’envoie lecture, pause ou morceau suivant à Musique que quand tu cliques. Rien ne quitte ton ordinateur.

7. E-mail

Quand tu envoies un fichier par e-mail, le message est créé et envoyé par ta propre app Mail. Coucou n’envoie jamais d’e-mail de lui-même.

8. Autorisations système

Selon la version et les fonctions utilisées, macOS peut te demander d’autoriser l’Automatisation (Mail, Terminal), l’Accessibilité (lire le titre de la fenêtre que tu attaches) ou l’Enregistrement de l’écran (capturer une fenêtre que tu attaches). Elles ne servent qu’à la fonction que tu as déclenchée et se retirent à tout moment dans Réglages Système → Confidentialité et sécurité. Les versions Windows et Linux ne demandent aucune autorisation particulière. Sous Linux, l’installation du paquet .deb ou .rpm nécessite des droits administrateur ; l’AppImage non.

9. Enfants

Coucou est un outil pour développeurs, il ne s’adresse pas aux enfants.
