Motion spec kept verbatim vs extended

Kept verbatim

  • Agent switch blur(8px)+scale(.97) out → headIn blur-in on the conductor, exactly the existing view swap.
  • Pill flight a dot clone flies translate(dx,dy), 950ms, then 14 burst particles radial — the same flight, re-aimed avatar-to-avatar.
  • Mochi hop squash-stretch 1.25,.72 → .88,1.15 → settle + ring spinner in the agent color, on both the conductor and the minis.
  • Thread swap steps swap-in cascade from the left with the same stagger.
  • Chrome #000 island, #141518 cards, rgba(255,255,255,.07) lines, dark-only.

Extended (and why it still feels like Coucou)

  • Avatar-to-avatar flight — the existing pill→Mochi flight is aimed between two roster avatars instead of pill→Mochi. Same 950ms, same burst, so the handoff reads as the gesture you already know.
  • Conductor identity tint — the big Mochi takes the focused workspace's color as its body tint (the notch already tints by agent). Main stays neutral white with a ✦ twinkle.
  • Stage board — plan steps + tool trail live in one panel; it is the notch's task ticker, laid out vertically. Same shimmer, same status colors.
  • Mini roster — the compact-mode mini-bonhommes promoted to a persistent roster, so Main and every workspace are always one tap away.
Why it still feels like the same app: every movement is one of the four gestures already in the notch — hop, blur-swap, flight+burst, cascade — just with Main and the workspaces on the same stage instead of hidden behind pills.
