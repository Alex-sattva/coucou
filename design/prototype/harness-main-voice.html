Motion spec kept verbatim vs extended

Kept verbatim

  • Overview layout — big Mochi left, agent line + task ticker right, 2×2 mini-Mochi pills — straight from notch-buddy.
  • Ticker 30pt lines, current line shimmering at 2.2s, 450ms cubic-bezier(.3,.9,.3,1) roll.
  • Spring cubic-bezier(.32,1.22,.42,1) on pill lifts, riser and view swaps.
  • Mochi hop squash-stretch + ring spinner in the agent color on every focus change.
  • Wash radial tint of the left card, per focused agent; #000 island, #141518 cards, dark-only.

Extended (and why it still feels like Coucou)

  • Voice bar — mic + waveform + spoken line sit in the left card footer, reusing the notch's ping ring and breathe timing. It is a channel, not a chat: it shows the agent's state and your own words, never the agent's replies — the 1-liner is spoken and carried by the summary card.
  • Mini-Mochis = workspaces — the catalog pills are re-bound to project folders; the mini body is filled with the agent color exactly like the compact-mode mini-bonhommes, and the blue working ring is unchanged.
  • Voice approvals, inline — the permission card is a quiet strip that opens in-flow just above the voice bar (thin border, no glow, no modal), and is answerable by voice (“yes / no / show diff”) with buttons as fallback.
  • Main-lurk — the top-right mochi chip shows Main when a workspace has taken the stage; tap to return.
  • Done summary — when an agent finishes, the ticker is replaced by a summary card in the same slot, to the right of the Mochi: just the done header and the one-liner, nothing else.
  • Suggested prompt — the agent's next-step hint sits in the composer as a greyed, italic placeholder (same input slot, no new control). Tab or → fills it in; typing instead leaves the field empty at the top-left with room for more lines below. The composer is capped at three lines — it scrolls inside past that, so the island height never moves. While an approval/plan strip is up, the composer drops its caption so the strip still fits without resizing the card.
Why it still feels like the same app: it is the shipped overview, unchanged in shape and motion. Voice is the only new control, and the pills simply point at folders instead of integrations.
