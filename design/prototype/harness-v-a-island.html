Motion spec kept verbatim vs extended

Kept verbatim

  • Spring cubic-bezier(.32,1.22,.42,1) on every strip/panel swap.
  • Mochi hop squash-stretch 1.25,.72 → .88,1.15 → settle, plus workspace-colored ring spinner.
  • Wash radial tint from the bottom-left of the row, per workspace color.
  • Motion states listening = breathe 1.6s, speaking = talk chomp .5s, working = tilt-bounce 1.2s, shimmer sweep on the working line.
  • Chrome #000 island, #141518 cards, rgba(255,255,255,.07) lines, 18–24px radii, dark-only.

Extended (and why it still feels like Coucou)

  • Status line as harness — the tool trail, diff, cost and model collapse into one line + 4 pips. It reuses the same shimmer and the same workspace wash, so it reads as the existing "working" state, just denser.
  • Growing strip — approval/plan slide down using the island's own spring; it is the same expand idiom as the notch, so no new easing was introduced.
  • Voice row — waveform reuses the ping ring + breathe timing; push-to-talk is the only new control, styled as the existing circular sicon.
  • Main-lurk pill — same pill language, just parked at the row's end instead of the roster.
  • Agent roster dots — the notch's compact mini-bonhomme grid, reduced to one colored dot per running agent with the same blue working spinner. It keeps the row one-line tall while letting several agents show at once.
Why it still feels like the same app: nothing about the island's shape, palette, easing or avatar behavior changed. The only new thing is what the one existing line is allowed to say.
