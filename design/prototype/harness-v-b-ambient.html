Motion spec kept verbatim vs extended

Kept verbatim

  • Spring cubic-bezier(.32,1.22,.42,1) on the approval riser and all card lifts.
  • Mochi hop squash-stretch on every state handoff, ring spinner in the workspace color.
  • Wash the same radial gradient formula from the left card — now the whole room's mood light.
  • States listening = breathe 1.6s, speaking = talk chomp .5s, working = tilt-bounce 1.2s, shimmer on the spoken line.
  • Chrome #000 island, #141518 cards, rgba(255,255,255,.07) lines, dark-only.

Extended (and why it still feels like Coucou)

  • Room wash — the existing wash is scaled from a card corner to the whole island. Same gradient, same 0.9s ease, so it reads as the same lighting rig.
  • Waveform ring — the notch's ping ring reused as concentric voice rings; the timing (1.6s listening) is unchanged, only the count grew.
  • Orbit cards — tool trail / cost / model are the same cards from the harness board, shrunk and floated on a slow 6s sine. They stay at 0.6 opacity so Mochi is still the subject.
  • Approval riser — rises from the room floor on the island spring; same amber wash token as the notch approval view.
Why it still feels like the same app: it is the notch's own wash, ring and card vocabulary at a larger scale — no new easing, no new palette, no new shape. The room is just the left card grown up.
